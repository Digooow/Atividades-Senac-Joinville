# Atividades de Desenvolvimento Web

Exercícios e pequenos projetos desenvolvidos durante os estudos de Desenvolvimento Web no SENAC Joinville e no curso **HTML Essentials**, da Cisco.

O diretório reúne páginas estáticas feitas com **HTML**, **CSS** e **JavaScript**, com exemplos de estrutura semântica, estilização responsiva, formulários, validação de dados, eventos do navegador e composição de interfaces.

## Atividades do Desenvolvimento Web SENAC

### Atividade 1

Conjunto de páginas HTML independentes (`Atividade 1.html` até `Atividade 9.html`) para praticar a construção de documentos e interfaces com HTML e CSS.

### Formulário JavaScript

Projeto de formulário de contato composto por:

- [`Atividade.html`](<Atividades Curso Desenvolvimento Web SENAC/Atividade formulario JavaScript/Atividade.html>): formulário com nome, e-mail, telefone, idade e mensagem;
- [`Atividade.css`](<Atividades Curso Desenvolvimento Web SENAC/Atividade formulario JavaScript/Atividade.css>): estilos da interface;
- [`Atividade.js`](<Atividades Curso Desenvolvimento Web SENAC/Atividade formulario JavaScript/Atividade.js>): validação dos campos, mensagens de erro, estados de acessibilidade e confirmação do envio;
- [`pagina.html`](<Atividades Curso Desenvolvimento Web SENAC/Atividade formulario JavaScript/pagina.html>): exemplos de eventos JavaScript, incluindo `click`, `change`, `submit`, `focus`, `blur` e `keydown`.

O formulário valida, entre outros critérios, nome com pelo menos três letras, formato de e-mail, telefone com 10 ou 11 dígitos, idade entre 1 e 120 anos e mensagem com pelo menos 10 caracteres. O envio é simulado no navegador, sem conexão com um servidor.

## Como executar

Não há dependências ou processo de compilação. Para visualizar qualquer atividade:

1. Abra a pasta da atividade.
2. Abra o arquivo `.html` no navegador; ou use a opção **Open with Live Server** no VS Code.
3. Ao abrir um projeto com arquivos relacionados, mantenha a estrutura de pastas para que os links de CSS, JavaScript e imagens funcionem corretamente.

Algumas páginas carregam fontes ou imagens hospedadas externamente e, por isso, podem apresentar diferenças visuais quando abertas sem conexão com a internet.

## Tecnologias praticadas

- HTML5 e elementos semânticos;
- CSS3, incluindo Flexbox, media queries, gradientes, animações e efeitos de transparência;
- JavaScript no navegador e manipulação do DOM;
- Validação de formulários e eventos de interação;
- Acessibilidade básica com `label`, `aria-invalid` e `aria-live`;
- Organização de páginas estáticas e referências entre arquivos.
