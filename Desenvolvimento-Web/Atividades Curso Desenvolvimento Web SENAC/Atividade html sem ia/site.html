Sobre mim

Sou um desenvolvedor Full Stack com paixão por construir soluções escaláveis e bem estruturadas. Minha stack principal combina .NET no backend com React no frontend.

Acredito que um bom desenvolvedor não se limita a dominar linguagens e ferramentas – também aplica princípios sólidos de engenharia de software para construir sistemas manuteníveis, testáveis e escaláveis.

🏛️ Arquitetura

  • MVC – Separação em Model, View e Controller
  • MVVM – Model-View-ViewModel para WPF/XAML
  • Clean Architecture – Camadas isolando regras de negócio
  • Microsserviços – Arquitetura distribuída e escalável

📐 Princípios

  • SOLID – Código orientado a objetos coeso e flexível
  • Design Patterns – Soluções reutilizáveis (Factory, Repository)
  • DDD – Modelagem focada no domínio
  • Clean Code – Código legível e expressivo

🧪 Testes

  • TDD – Testes antes do código
  • Testes Unitários – Comportamento isolado
  • Testes de Integração – Interação entre componentes

🚀 Metodologias & DevOps

  • Scrum – Entregas incrementais
  • Kanban – Fluxo contínuo com WIP
  • DevOps – Integração desenvolvimento e operações
  • CI/CD – Automação com GitHub Actions, Azure Pipelines

🌐 APIs & Integração

  • RESTful – Recursos e verbos HTTP
  • Swagger (OpenAPI) – Documentação interativa
  • Postman – Teste e monitoramento de APIs
