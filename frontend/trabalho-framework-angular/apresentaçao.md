O que é?
-Angular é um framework de código aberto baseado em TypeScript, ele é uma reescrita completa do AngularJS produzida pela mesma equipe

Para que serve e o que resolve?
-Angular é utilizado para criar aplicações web dinâmicas, modernas e escalaveis como Single Page Applications (SPA), o framework oferece uma plataforma robusta e escalavel, permitindo a reutilização de código e manutenção facil de aplicações web complexas

Quem criou e em que ano surgiu?
-Ele foi lançado em 14 de setembro de 2016 pela Equipe Angular do Google em conjunto de corporações e individuos

Como evoluiu e onde é utilizada?
-Originalmente sendo uma releitura do AngularJS (1.X), foi nomeado como Angular 2 e posteriormente nomeado apenas como Angular. O projeto deste seminário utiliza a versão 21 (v21.2).
-Ele é utilizado como framework para aplicações web (SPAs)

O que é necessario instalar para começar?
-Para instalar o Angular, é necessario instalar o node.js e a instalação do Angular em npm no terminal

Como criar um projeto do zero?
-Para criar um projeto Angular é necessario rodar o comando "ng new <nome desejado>", escolher a configuração de rotas (URLs) e qual pré-processador CSS que você usará. Após isso o terminal gerará todas as dependencias e arquivos necessarios para iniciar o projeto

Quais são os principais arquivos e pastas do projeto?
-as pastas mais importantes são: 
src = é onde ficara toda a aplicação, sendo a pasta central e mais importante do projeto
app = onde se encontra todos os componentes, serviços e rotas da aplicação
assets = (geralmente criada posteriormente) é onde se encontra os arquivos estaticos como imagens
environments = contem arquivos de configuração especifica pra cada ambiente
a partir disso existem arquivos especificos para diferentes funções como:
app (html e css) = onde será construida o esqueleto html e a estilização css do componente raiz
app.ts = onde será conectada a lógica TypeScript com o template HTML e os componentes

Como executar a aplicação no navegador?
-Para executar a aplicação no navegador, basta executar o comando "ng serve" e abrir o link `http://localhost:4200` no navegador padrão

Qual foi a maior facilidade encontrada?
-a maior facilidade foi a organizaçao entre as pastas, a liberdade de modificação dos site e dos componentes e a pré criação de multiplos serviços necessarios para a funcionalidade da aplicação

Qual foi a maior dificuldade?
-a maior dificuldade foi a falta de explicação sobre o propósito das pastas pré criadas

Em que tipo de projeto a tecnologia seria útil?
-o framework Angular apresenta uma adequação maior pra criação de sites web principalmente focados em vendas
e paginas unicas (SPA's)

O que muda em relação a HTML, CSS e JavaScript puros?
-Além da atualização automatica no site, o Angular fornece testes pré criados, abertura de servidores e funções e linguagem adaptada e complementada
