Conjunto de exercícios desenvolvidos durante as aulas de lógica de programação e qualidade de software do curso **Jovem Programador (SENAC Joinville)**. Os arquivos praticam entrada e saída de dados, variáveis, estruturas condicionais, repetição, vetores, refatoração SOLID e testes unitários em console.

## Organização

### [`Atividades algoritmos/`](./Atividades%20algoritmos/)

Exercícios introdutórios em C++:

- [`Atividade para fazer em casa111.cpp`](./Atividades%20algoritmos/Atividade%20para%20fazer%20em%20casa111.cpp): soma continuamente números informados pelo usuário, trata entradas inválidas e encerra quando `n` é digitado.
- [`Atividade para fazer em casa112.cpp`](./Atividades%20algoritmos/Atividade%20para%20fazer%20em%20casa112.cpp): solicita uma senha até que o valor correto seja informado.
- [`Atividade para fazer em casa113.cpp`](./Atividades%20algoritmos/Atividade%20para%20fazer%20em%20casa113.cpp): exibe a tabuada de um número de 1 a 10.
- [`Atividade para fazer em casa114.cpp`](./Atividades%20algoritmos/Atividade%20para%20fazer%20em%20casa114.cpp): calcula a média de várias notas e informa se o aluno foi aprovado ou reprovado.
- [`Atividade para fazer em casa115.cpp`](./Atividades%20algoritmos/Atividade%20para%20fazer%20em%20casa115.cpp): simula uma compra em uma padaria, calculando o total, o troco ou o valor restante.
- [`Atividade para fazer em casa116.cpp`](./Atividades%20algoritmos/Atividade%20para%20fazer%20em%20casa116.cpp): recebe notas entre 0 e 10, lista os valores e calcula a média.

### [`Atividades Portugol/`](./Atividades%20Portugol/)

Algoritmos em Visualg usados para exercitar a lógica antes da implementação em uma linguagem compilada:

- [`Calculadora.visualg`](./Atividades%20Portugol/Calculadora.visualg): realiza operações de adição, subtração, multiplicação e divisão, permitindo continuar a conta.
- [`Escolha o número e direi o mês.visualg`](./Atividades%20Portugol/Escolha%20o%20n%C3%BAmero%20e%20direi%20o%20m%C3%AAs.visualg) e [`Escolha o número e direi o mês (1).visualg`](./Atividades%20Portugol/Escolha%20o%20n%C3%BAmero%20e%20direi%20o%20m%C3%AAs%20%281%29.visualg): relacionam um número ao mês correspondente.
- [`Leia a nota do aluno.visualg`](./Atividades%20Portugol/Leia%20a%20nota%20do%20aluno.visualg): recebe uma nota e trabalha sua classificação.
- [`Leia um numero e faça tabuada.visualg`](./Atividades%20Portugol/Leia%20um%20numero%20e%20fa%C3%A7a%20tabuada.visualg): gera a tabuada de um número informado.
- [`Leia um número e diga se ele é impar o par.visualg`](./Atividades%20Portugol/Leia%20um%20n%C3%BAmero%20e%20diga%20se%20ele%20%C3%A9%20impar%20o%20par.visualg): identifica se o número é par ou ímpar.
- [`Meu número premiado.visualg`](./Atividades%20Portugol/Meu%20n%C3%BAmero%20premiado.visualg): soma números até que o valor zero seja informado.

## Como executar os arquivos C++

É necessário ter um compilador C++ instalado (como GCC/MinGW). Alguns programas utilizam `windows.h`, portanto foram preparados para execução no Windows.

No terminal, entre na pasta que contém o arquivo e compile com:

```bash
g++ "nome-do-arquivo.cpp" -o programa.exe
```

Depois, execute o programa:

```powershell
.\programa.exe
```

Os arquivos `.visualg` devem ser abertos no Visualg ou em um interpretador compatível com a sintaxe Portugol.

## Objetivo dos exercícios

As atividades formam uma sequência prática de aprendizagem: começam com algoritmos simples em Portugol, avançam para programas interativos em C++ e terminam com avaliação de qualidade, refatoração SOLID e testes unitários. Os executáveis presentes nas pastas são resultados de compilações anteriores; para reproduzir os programas, recomenda-se compilar novamente os arquivos-fonte `.cpp`.
